This repo contains an automated scanner that searches for apps that make use of the Shizuku Android application (an app that exposes ADB-level permissions via wireless ADB to normal apps). We are crawling GitHub, F-Droid, and IzzySoft's F-Droid repo for these apps.

We maintain ignore-lists, that exclude known repos/apps that do not fit our requirements and that are ignored in future crawling runs and eliminated from the summary list. You can find these lists in @ignore. They are categorized into several separate lists that also contain different subsections within the file in the format of: "# This is a subsection".

The summary list generated by the crawler is found at @SUMMARY.md (or @SUMMARY_RANKED.md).

It is used to keep my awesome-shizuku list up-to-date, which you can find at @../awesome-shizuku. Requirements for adding new list items can be found at: @../awesome-shizuku/CONTRIBUTING.md.
